# 🔍 Qiuzhi Agent — 求职者深度背调助手

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
![Version](https://img.shields.io/badge/version-1.0-3f51b5)

基于 [Beijing Agent](https://github.com/wendy-cool/BGC---agent) 架构重设计，面向**求职者**的公司与产品深度背调工具。输入目标公司名称，自动完成公司画像、产品矩阵分析、竞品对比、面试策略生成，输出结构化的求职背调报告。

> **核心定位**：帮求职者回答三个问题 —— 值不值得去？去了做什么？面试怎么聊？

---

## 与 Beijing Agent 的差异

| 维度 | Beijing（销售版） | Qiuzhi（求职版） |
|------|-------------------|---------------------|
| 核心问题 | 能不能成交？ | 值不值得去？ |
| 产品分析 | 产品匹配度评估 | **产品内部横向对比 + 技术栈拆解** |
| 竞品分析 | 竞品替代策略 | **竞品全景图 + 能力逐项PK + 求职含义** |
| 组织分析 | 决策链角色（DM/EV/RC） | **团队结构 + 技术文化 + 关键人物** |
| 核心输出 | 会客话术 | **面试攻略 + 求职决策矩阵** |
| 独有模块 | — | 加权评分模型、薪资谈判参考、入职前验证清单 |

## 四种能力

### 单公司背调

| 模式 | 命令 | 内容 | 用时 |
|------|------|------|------|
| 快速 | `/qiuzhi <公司名>` | 6 大模块：公司基本面、产品总览、人才信号、风险清单、求职速评、信息核实 | ~5 min |
| 深度 | `/qiuzhi --deep <公司名>` | 快速全部 + 产品深度拆解、竞品对比、组织洞察、面试攻略、薪资发展、决策矩阵 | ~15 min |
| 岗位定制 | `/qiuzhi <公司名> --position "岗位"` | 深度模式 + 技术栈精准匹配 + 岗位面试备战 + 薪资精准参考 | ~15 min |

### 行业全景扫描

| 模式 | 命令 | 内容 | 用时 |
|------|------|------|------|
| 快速扫描 | `/qiuzhi --industry "行业名"` | 5 大模块：行业全景、20 家公司深挖、横向对比矩阵、求职策略、信息核实 | ~8 min |
| 深度扫描 | `/qiuzhi --industry "行业名" --deep` | 快速全部 + TOP10 扩展分析、人才市场深度、分类面试策略、风险全景图、决策看板 | ~15 min |
| 经历匹配 | `/qiuzhi --industry "行业名" --resume "经历"` | 扫描模式 + 基于用户背景的岗位精准匹配 + 个性化推荐排序 | ~8 min |
| 岗位聚焦 | `/qiuzhi --industry "行业名" --deep --position "岗位"` | 深度扫描 + 聚焦特定岗位方向 | ~15 min |

## 快速开始

### 1. 安装

```bash
mkdir -p ~/.claude/skills/qiuzhi
cp SKILL.md ~/.claude/skills/qiuzhi/
```

重启 Claude Code，Skill 自动注册。

### 2. 使用

```bash
# 单公司背调
/qiuzhi 字节跳动                              # 快速模式
/qiuzhi --deep 帆软                           # 深度模式
/qiuzhi --deep 帆软 --position "招聘实习生"    # 岗位定制

# 行业全景扫描（新）
/qiuzhi --industry "消费电子出海"                                     # 快速行业扫描
/qiuzhi --industry "商业SaaS出海" --deep                              # 深度行业扫描
/qiuzhi --industry "消费电子出海" --resume "3年Java后端，熟悉Spring"    # 带经历匹配
/qiuzhi --industry "消费电子出海" --deep --position "后端开发"          # 深度 + 岗位聚焦
```

### 3. 用户档案（可选）

创建 `~/.claude/skills/qiuzhi/profile.md` 保存你的求职档案，行业扫描时自动读取进行岗位匹配：

```bash
cp ~/projects/qiuzhi-agent/profile.example.md ~/.claude/skills/qiuzhi/profile.md
# 编辑 profile.md 填写你的信息
```

也可以直接通过 `--resume "经历描述"` 传入，优先级高于 profile.md。

### 4. 输出

报告自动保存至桌面：
- 单公司快速 → `~/Desktop/{公司名}_求职背调_快速_{日期}.md`
- 单公司深度 → `~/Desktop/{公司名}_求职背调_深度_{日期}.md`
- 行业扫描快速 → `~/Desktop/{行业关键词}_行业扫描_快速_{日期}.md`
- 行业扫描深度 → `~/Desktop/{行业关键词}_行业扫描_深度_{日期}.md`

### 5. 导出

```bash
# 打印优化 HTML（浏览器打开，直接 Cmd+P）
npm install
node scripts/to-print.js ~/Desktop/帆软_求职背调_深度_20260516.md

# Word 文档（.docx，完整保留表格和格式）
python3 scripts/to-docx.py ~/Desktop/帆软_求职背调_深度_20260516.md
```

## 核心设计

### 1. 求职视角翻译（最重要）

不是写公司百科，而是帮求职者做出理性决策。每个事实都回答："这对求职者有什么用？"

| 原始信息 | 求职视角翻译 |
|---------|------------|
| "公司有 2000 名员工" | 2000 人规模意味着流程相对成熟，不会陷入混沌期，但也别期待创业公司的扁平灵活 |
| "产品 A 月活 100 万" | 产品用户基数大，你做的工作会影响真实用户，有成就感。但需求变更要兜底，灰度发布流程可能比较长 |
| "刚融资 10 亿" | 2-3 年内现金流安全，但团队即将快速膨胀，入职 6 个月内可能经历组织调整——适合能适应变化的人 |
| "CTO 来自阿里巴巴" | 技术文化大概率偏"正规军"：流程规范、文档先行、晋升通道清晰。如果你习惯野蛮生长风格，需要适应期 |

### 2. 并行搜索架构

```
第 1 轮：公司与产品画像（5 个搜索并行）
  ├── 公司基本信息、融资上市
  ├── 官网、主营业务、产品矩阵
  ├── 最新新闻和动态
  ├── 招聘岗位、薪资福利、技术栈
  └── 员工评价、工作体验、口碑

第 2 轮：产品深度与竞争（5 个搜索并行）
  ├── 核心产品用户量、市场份额、竞争对手
  ├── 技术架构、技术栈
  ├── 行业竞争格局和排名
  ├── 与竞品的差异对比
  └── 产品路线图、研发方向

第 3 轮：深度信息（4 个搜索并行，仅 --deep）
  ├── 组织架构、部门、团队规模
  ├── 创始人、CTO 背景履历
  ├── 裁员、负面、诉讼、风险
  └── 面试面经、招聘流程
```

### 3. 信息可信度标记

| 标记 | 含义 | 示例来源 |
|------|------|---------|
| 🔴 官方 | 公司官方渠道 | 官网、招聘官网、财报、官方博客 |
| 🟡 第三方 | 独立媒体/社区 | 新闻报道、行业研报、面经社区 |
| 🟠 推测 | 基于公开信息的有依据推断 | "从招聘JD推断技术栈为React" |
| ⚪ 待核实 | 需要手动确认 | 脉脉私信员工、亲自试用产品 |

### 4. 求职决策矩阵

采用 6 维度加权评分模型，权重可按个人偏好调整：

| 维度 | 建议权重 | 说明 |
|------|---------|------|
| 💰 薪资回报 | 20% | 现金+股票+福利 |
| 📈 成长空间 | 25% | 技能成长+职级晋升 |
| 🛡 稳定性 | 15% | 业务安全垫+资金状况 |
| 🧠 技术氛围 | 20% | 技术栈先进性+团队技术密度 |
| ⚖️ 工作生活平衡 | 10% | 加班文化+弹性办公 |
| 🌐 行业前景 | 10% | 赛道天花板+增长持续性 |

## 项目结构

```
qiuzhi-agent/
├── README.md                   # 项目说明（本文件）
├── CHANGELOG.md                # 版本更新日志
├── LICENSE                     # MIT License
├── SKILL.md                    # Claude Code Skill 核心 Agent Prompt（925行）
├── profile.example.md          # 用户档案模板（复制到 ~/.claude/skills/qiuzhi/profile.md）
├── package.json                # Node.js 项目配置（marked 依赖）
├── package-lock.json           # 依赖锁定
├── .gitignore
├── scripts/
│   ├── to-print.js             # .md → A4 打印优化 HTML（蓝色主题，264行）
│   ├── to-docx.py              # .md → 排版良好 .docx（基于 python-docx，230行）
│   └── to-docx.js              # .md → .docx Node.js 封装（macOS textutil）
└── examples/
    └── 帆软_求职背调_深度_20260516.md  # 帆软软件 × 招聘实习生 完整报告（13章）
```

**SKILL.md** 是整个项目的核心——它是 Claude Code 执行 `/qiuzhi` 命令时加载的完整 Agent 提示词，定义了：
- 触发方式和参数解析（`--deep`、`--position`、`--industry`、`--resume`）
- 模式判断分支（单公司 vs 行业扫描）
- 单公司模式：3 轮 14 个并行搜索 + 快速/深度报告模板
- 行业扫描模式：3 轮 20 个并行搜索 + 行业全景报告模板（含 20 家公司深挖）
- 求职视角翻译的核心原则
- `--position` 岗位定制的 4 维度匹配分析框架
- 用户档案机制（`--resume` / `profile.md`）
- 17 条实现注意事项
