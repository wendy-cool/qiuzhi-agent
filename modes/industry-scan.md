# 模式B：行业全景扫描

> 本文件由 SKILL.md 路由加载。执行前确保已理解核心原则（求职视角翻译、并行搜索、信息可信度标记）。

## --industry 行业扫描模式

当用户通过 `--industry "行业名"` 触发行业扫描时，你的任务是：发现该行业中值得投递的 20 家公司，结合用户背景做岗位匹配，生成结构化的行业求职报告。

### 与单公司模式的区别

| 维度 | 单公司模式 | 行业扫描模式 |
|------|----------|------------|
| 输入 | 一家公司名 | 一个行业/赛道名 |
| 核心问题 | 值不值得去？去了做什么？面试怎么聊？ | 这个行业有哪些好公司？我适合投哪家？怎么准备？ |
| 搜索策略 | 针对一家公司深挖 | 先发现行业全景，再批量调研 20 家公司 |
| 输出 | 单公司深度背调报告 | 行业全景扫描 + 20 家公司深挖 + 求职决策矩阵 |
| 用时 | 快速 5 分钟 / 深度 15 分钟 | 快速 8 分钟 / 深度 15 分钟 |

### --resume 和 profile.md

**用户档案加载优先级**：
1. 如果指定了 `--resume "经历描述"` → **直接使用**该文字作为用户背景
2. 否则，尝试用 Read 工具读取 `~/.claude/skills/qiuzhi/profile.md`
3. 如果 profile.md 存在 → 将其内容作为用户档案
4. 如果都不存在 → 生成通用报告（不针对特定用户背景），并在报告末尾提醒用户可以创建 profile.md 或使用 --resume 来获得个性化岗位匹配

**用户档案的使用方式**：
- 在 20 家公司中发现与用户经历匹配的岗位
- 调整公司推荐排序（与用户背景高度匹配的公司排前面）
- 在每家公司的"适合你的岗位"部分做精准推荐
- 在"准备方向"中结合用户现有技能给出补强建议

**profile.md 模板**（用户可在 `~/projects/qiuzhi-agent/profile.example.md` 找到参考模板）：
- 基本信息：当前职位、工作年限、教育背景、目标城市
- 技能与经验：核心技术栈、行业经验、代表项目
- 求职偏好：目标岗位类型、期望薪资、公司规模偏好、工作方式
- 个人优势：核心竞争力、差异化亮点
- 其他：签证状态，补充信息

### --position 在行业扫描中的作用

如果在行业扫描中同时指定了 `--position "岗位名"`，它作为**岗位过滤器**：
- 每家公司的岗位推荐聚焦该岗位方向
- 横向对比矩阵按该岗位的薪资水平排序
- 面试策略按该岗位类型分类（技术岗 vs 产品岗 vs 运营岗）

### 【模式B：行业扫描模式】

#### ⚠️ 档案加载（搜索前必须完成）

在开始搜索前，确定用户档案：

1. 如果用户指定了 `--resume "经历"` → **直接使用**该文字
2. 否则，用 Read 工具读取 `~/.claude/skills/qiuzhi/profile.md`
3. 若读取成功 → 将其内容作为用户档案
4. 若读取失败（文件不存在）→ 标记"无用户档案"，后续生成通用报告

#### 阶段一：行业发现（必做，6 个并行搜索）

```
搜索 1: "{行业} 行业排名 头部公司 TOP20 市场份额 {今年}"
搜索 2: "{行业} 最佳雇主 员工口碑 值得加入 推荐公司 薪资"
搜索 3: "{行业} 独角兽 高成长 创新公司 出海 融资 {今年}"
搜索 4: "{行业} 行业报告 市场规模 发展趋势 前景 {今年}"
搜索 5: "{行业} 招聘需求 热门岗位 人才缺口 薪资水平 {今年}"
搜索 6: "{行业} 细分赛道 竞争格局 技术趋势 头部差异化"
```

阶段一完成后，从搜索结果中**提取 20 家目标公司**：
- 优先选择信息完整、有明确招聘需求的公司
- 覆盖行业不同细分赛道（不要全是大厂或全是初创）
- 结合用户档案（如有），优先纳入与用户背景匹配度高的公司
- 按综合推荐度排序：用户匹配度 > 公司实力 > 增长潜力 > 员工口碑
- 如果搜索结果中可识别的优质公司不足 20 家，诚实标注实际数量，不要编造

#### 阶段二：批量公司调研（必做，8 个并行搜索）

将 20 家公司分成 4 组（每组 5 家），分批搜索基本信息。同时用 4 个行业级搜索补全薪资、文化、风险等横切信息：

```
搜索 7:  "{公司1-5的名字，用空格分隔} 主营业务 产品 规模 融资 出海"
搜索 8:  "{公司6-10的名字，用空格分隔} 主营业务 产品 规模 融资 出海"
搜索 9:  "{公司11-15的名字，用空格分隔} 主营业务 产品 规模 融资 出海"
搜索 10: "{公司16-20的名字，用空格分隔} 主营业务 产品 规模 融资 出海"
搜索 11: "{行业} 头部公司 招聘 技术栈 薪资 福利 社保 公积金 文化 {今年}"
搜索 12: "{行业} 公司薪资排名 薪酬对比 福利待遇 社保 公积金 年终奖 {今年}"
搜索 13: "{行业} 头部公司 员工评价 脉脉 知乎 工作体验 离职原因 加班 氛围"
搜索 14: "{行业} 裁员 劳动仲裁 负面 风险 暴雷 高管变动 {今年}"
```

> 搜索 7-10 中，将实际公司名填入占位符。如果某个分组少于 5 家，对应的搜索合并即可。

#### 阶段三：聚焦深挖（仅 --deep 模式，6 个并行搜索）

```
搜索 15: "{TOP3公司名，空格分隔} 产品技术 技术架构 GitHub 开源 创新 研发方向"
搜索 16: "{TOP3公司名，空格分隔} 面试 面经 招聘流程 笔试 面试题"
搜索 17: "{TOP4-8公司名，空格分隔} 产品技术 技术架构 研发"
搜索 18: "{TOP4-8公司名，空格分隔} 面试 面经 招聘流程"
搜索 19: "{行业} 企业增长潜力 估值排名 融资动态 对比 {今年}"
搜索 20: "{行业} 政策 监管 出海趋势 国际化 挑战 {今年}"
```

> TOP3 和 TOP4-8 基于阶段一 + 阶段二的结果重新排名，结合用户档案匹配度。

#### 阶段四：信息整合与用户匹配

1. **行业全景点评**：市场规模、增长阶段、人才需求特征、薪资水位
2. **20 家公司排序**：按用户匹配度 + 公司实力综合排序
3. **逐家生成推荐**：每家公司生成"为什么值得投"、"适合你的岗位"、"准备方向"、"⚠️注意"
4. **横向对比**：薪资梯队、技术方向、WLB、增长阶段的横向对比表
5. **求职策略**：投递优先级分组 + 行业通用准备建议

#### 阶段五：生成报告并保存

```
快速模式：~/Desktop/{行业关键词}_行业扫描_快速_{日期}.md
深度模式：~/Desktop/{行业关键词}_行业扫描_深度_{日期}.md
```

## 实现注意事项（本模式专属）

### 行业扫描模式专属

1. **档案加载优先**：行业模式下，在搜索前先尝试加载用户档案（--resume > profile.md）
2. **20 家公司筛选**：从阶段一结果中提取，优先选择信息完整、有招聘需求、与用户背景匹配的公司；强公司数量不足时诚实标注
