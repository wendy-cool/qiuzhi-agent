# 模式A：单公司背调（默认模式）

> 本文件由 SKILL.md 路由加载。这是 /qiuzhi 的默认模式——输入公司名即可触发。
> 执行前确保已理解核心原则（求职视角翻译、并行搜索、信息可信度标记）和 --position 岗位定制模式。

## 核心问题

帮求职者回答三个问题：**值不值得去？去了做什么？面试怎么聊？**

### 【模式A：单公司背调模式】

#### 阶段一：并行搜索（3 轮）

**第 1 轮 — 公司与产品画像（必做，6 个并行搜索）**

```
搜索 1: "{公司名} 成立时间 融资 上市 财报 营收"
搜索 2: "{公司名} 官网 主营业务 产品矩阵"
搜索 3: "{公司名} 最新新闻 动态 {今年} {去年}"
搜索 4: "{公司名} 招聘 岗位 薪资 福利 社保 公积金 技术栈"
搜索 5: "{公司名} 员工评价 脉脉 知乎 工作体验 离职原因 加班"
搜索 6: "{公司名} 裁员 经营风险 劳动仲裁 口碑 {今年}"
```

**第 2 轮 — 产品深度与竞争（必做，5 个并行搜索）**

```
搜索 7: "{公司名} {核心产品} 用户量 市场份额 竞争对手"
搜索 8: "{公司名} {核心产品} 技术架构 技术栈 GitHub 开源 研发"
搜索 9: "{行业关键词} 竞争格局 市场份额 排名 {今年}"
搜索 10: "{公司名} 与 {竞品1} 对比 差异 优劣势"
搜索 11: "{公司名} 产品路线图 新功能 研发方向 {今年}"
```

> 注意：搜索 7、8、10 中的 {核心产品} 和 {竞品1} 需根据第1轮结果推断后填入，如果第1轮信息不足以确定，则搜索 "{公司名} 核心产品 竞品"

**第 3 轮 — 深度信息（仅 --deep 模式，4 个并行搜索）**

```
搜索 12: "{公司名} 组织架构 部门 团队 技术团队规模"
搜索 13: "{公司名} 创始人 CEO CTO 背景 履历"
搜索 14: "{公司名} 诉讼 财务危机 高管变动 股东变更 监管处罚 {今年}"
搜索 15: "{公司名} 面试 面经 招聘流程 面试题"
```

### 阶段二：信息整合与分析（在内存中完成）

1. **去重 & 矛盾检测**：不同来源对同一事实的说法是否一致？
2. **求职视角翻译**：把原始信息翻译成对求职者可行动的洞察
3. **提取关键信号**：融资/扩张/收缩/裁员/招聘规模/技术栈/薪资水平
4. **产品线梳理**：识别产品矩阵，判断各产品的生命周期和战略地位
5. **竞品对比提炼**：提炼该公司的竞争优势和产品差异化
6. **判断信息缺口**：哪些关键信息没搜到？标注待核实

### 阶段三：生成报告并保存

快速模式：`~/Desktop/{公司名}_求职背调_快速_{日期}.md`
深度模式：`~/Desktop/{公司名}_求职背调_深度_{日期}.md`

报告生成后，提醒用户可以打印或分享：
```
node ~/projects/qiuzhi-agent/scripts/to-print.js ~/Desktop/{报告文件名}.md
```

## 实现注意事项（本模式专属）

### 单公司模式专属

1. **如果指定了 --position**，必须贯穿全报告：技术栈分析聚焦该岗位、面试攻略针对该岗位、薪资参考对应岗位级别
2. **如果公司名模糊**，主动询问用户确认
3. **产品名称推断**：第1轮搜索后从结果中提取核心产品名称，填入第2轮搜索的占位符（搜索 7、8、10）
4. **竞品推断**：如果第1轮搜索未明确竞品名称，第2轮搜索中使用 "{公司名} 竞品 对手" 来发现
